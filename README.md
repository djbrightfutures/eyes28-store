## What it sees

- **Video** — any URL (~1800 sites) or local file → timestamped frames + on-device transcript
- **Web pages** — full-page tiles your model reads like a person: charts, tables and layout
  intact, including pages that hand a text scraper nothing at all
- **Pictures** — straight through
- **Voice** — including the sound *hiding after the words*: a hum, a track, another voice.
  Flagged, never silently dropped.

Works with **Claude Code, Cursor, and any model** that can run a command and read an image.
Runs fast on an ordinary laptop. Nothing leaves your machine.
